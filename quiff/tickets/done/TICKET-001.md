## Description

Build the account signup screen for a username, email address, password, and password confirmation. Submit the details to the signup endpoint and show a clear acknowledgment without claiming that an account was stored.

## Acceptance criteria

- [ ] The four required fields are present and labeled.
- [ ] The browser applies signup checks before sending the request.
- [ ] A valid response shows an acknowledgment that explains this demo does not create or store an account.
- [ ] The form is responsive and keyboard accessible.
